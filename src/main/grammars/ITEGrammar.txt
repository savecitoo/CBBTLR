S' -> S
S -> M | U
M -> If E Then M Else M #ite | While E Do M #while | Lgraph L Rgraph | A
U -> If E Then S #it | If E Then M Else U
L -> L Next S | S
A -> Id Equal E
E -> E Plus T | T
T -> T Times F #mul | F
F -> LParen E RParen | Id | Number
Token:
Plus : \+
Times : \*
LParen : \(
RParen : \)
If : if
Then : then
Else : else
While : while
Do : do
Lgraph : \{
Rgraph : \}
Next : ;
Equal : =
Number : [0-9][0-9]*
Id : [a-zA-Z][a-zA-Z]*
WS : [ \t\n]+ skip
